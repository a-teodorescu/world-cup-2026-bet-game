Admin scoruri meciuri

Introdu rezultatele reale pentru testare. După salvare, pagina de rezultate, culorile pronosticurilor, clasamentele grupelor și clasamentul userilor se recalculează automat.

Această secțiune este vizibilă doar pentru admin. În modul online, scorurile se salvează în Supabase și devin vizibile pentru toți userii.

Admin emailuri zilnice

Trimite fiecărui user un rezumat cu punctele obținute, scorurile exacte, pronosticurile corecte și poziția actuală în clasament.

Această secțiune este vizibilă doar pentru admin. Pentru trimitere reală trebuie configurate variabilele Netlify pentru Brevo. Poți trimite manual emailurile sau poți programa un test one-time al automatizării pentru o dată și oră alese de tine.
Test automatizare one-time Programează o singură rulare de test. Automatizarea reală de la 04:00 rămâne neschimbată.
Testul va trimite emailuri reale pentru data meciurilor selectată mai sus.

Admin API rezultate

Testează și compară sursele API pentru Cupa Mondială 2026 înainte să activăm sincronizarea automată a scorurilor.

Această secțiune testează API-urile și sincronizează scorurile/echipele reale din sursele externe. Admin scoruri rămâne backup manual.
Testele consumă requesturi din limitele zilnice ale furnizorilor. Sportmonks folosește SPORTMONKS_API_TOKEN, iar football-data.org folosește FOOTBALL_DATA_API_TOKEN. Butoanele de test pot scrie temporar în Supabase, dar au și reset dedicat.
